# Lapidary

Аддон для работы с чёрными бриллиантами на сервере **Sirus** (WoW 3.3.5a).

Помогает не возиться с камнями вручную: покупать нужные у огранщика, вынимать и вставлять их пачкой вместо перетаскивания по одному, и переносить между комплектами экипировки автоматически.

## У огранщика

Наведись на Велеса и выбери **«Огранить черный бриллиант»** — рядом с окном торговца откроется список всех камней, разложенных по группам: основные статы, вторичные, двойные, танковские.

В списке написано, что камень даёт: «+90 к силе атаки», «+46 к силе атаки и +22 к рейтингу критического удара». Это удобнее, чем названия — у всех бриллиантов одинаковая иконка, и «Яркий» от «Рунического» на глаз не отличить.

Покупка кликом по строке:

| | |
|---|---|
| **ЛКМ** | купить один |
| **Shift + ЛКМ** | купить десять |
| **Ctrl + ЛКМ** | купить столько, на сколько хватит валюты |
| **ПКМ** | добавить в избранное / убрать из избранного |
| **Alt + ЛКМ** | добавить один такой камень в активный комплект |
| **Alt + ПКМ** | убрать один камень из активного комплекта |

Понравившиеся камни можно собрать в **избранное**: ПКМ по строке — и камень с золотой звёздочкой переезжает в отдельный раздел *«Избранное»* в самом верху окна, прямо как любимые маунты или питомцы у Сируса. Там они всегда на виду, в порядке добавления, и их так же удобно покупать кликом.

## Комплекты (список покупок)

**«Комплекты»** — ваш список покупок. Комплект хранит, сколько каких камней нужно на персонажа: например, «ПвП» (N на хасту, N спд, N рес) или «ПвЕ» (N спд, N духа). Редактор открывается по кнопке **«Комплекты»** в правом верхнем углу списка покупки (повторное нажатие — «Скрыть») и не лезет на экран сам.

Редактор показывает **все группы камней** (основные, вторичные, двойные, танковские) в два столбца, и у каждой строки справа есть регулятор `- количество + :`  клик по `+` добавляет один такой камень в активный комплект, клик по `-` убирает. Сводка вверху сразу считает: *«в комплекте N · докупить M»*. Цифра возле камня горит золотом, пока чего-то не хватает, и зеленеет, когда уже всё куплено.

Комплектами легко переключаться стрелками `‹` `›`, название редактируется прямо в окошке, `+` создаёт новый комплект, `x` удаляет. `Alt + ЛКМ` по камню в правом списке покупки тоже добавляет его в комплект — как быстрый способ собрать всё с места покупки.

Раздел умный — камни, которые уже лежат в сумках, из покупки вычитаются. **«Купить всё (M)»** разом докупает весь недостающий набор целиком.
## Вернуть камень в исходный

Ветка **«Получить исходный черный бриллиант»** у того же торговца. Откроется список огранённых камней, которые лежат в сумках, с ценой возврата. Клик по строке — и камень снова становится обычным чёрным бриллиантом, готовым к новой огранке.

Порядок работы обычно такой: вынул камни из вещей → вернул их в исходные → погранил заново под другой стат.

## Кнопки на окне персонажа

Над моделью персонажа появляются четыре кнопки:

```
[  Достать  ]  [ Достать все  ]
[ Вставить  ]  [ Вставить все ]
```

**Левый блок** работает только с надетыми вещами. **Правый** — ещё и с вещами, которые лежат в сумках.

«Достать» вынимает все чёрные бриллианты разом. «Вставить» раскладывает камни из сумок по свободным гнёздам: мета-камни идут в мета-гнёзда, крупные вставляются раньше мелких.

Кнопка гаснет, когда делать нечего — например, «Вставить» при пустых сумках.

## Смена комплекта экипировки

Просто надень комплект через менеджер — камни переедут сами: сначала вынутся из старых вещей, потом вставятся в новые. Ничего нажимать не нужно.

Работает и с кнопкой «Надеть» в окне персонажа, и с командой `/equipset`.

## Команда

```
/lap toggle
```

Включает и выключает аддон. В выключенном состоянии он полностью бездействует: кнопки прячутся, панели не открываются.

`/lapidary` — то же самое, если удобнее писать полностью.

## Установка

Скопировать папку `Lapidary` в `Interface\AddOns\` и перезапустить игру.

Если стоит ElvUI, панели и кнопки оформятся под него автоматически.

# BlackDiamonds

Менеджер чёрных бриллиантов для WoW 3.3.5a, сервер Sirus.

## Что делает

- Панель у огранщика со всеми камнями, разложенными по группам статов. Покупка в один клик: ЛКМ — один камень, Shift+ЛКМ — десять, Ctrl+ЛКМ — сколько хватит валюты.
- Кнопки «Достать» и «Вставить» — вынуть все легендарные камни разом или разложить их из сумок по свободным гнёздам (мета в мета-гнёзда, крупные вперёд мелких).
- Автоматический перенос камней при смене комплекта экипировки: вынуть → надеть комплект → вставить обратно.

Панель появляется только в ветке «Огранить черный бриллиант» и не мешает в ветке «Получить исходный черный бриллиант».

## Команды

```
/bd out      вынуть все легендарные камни
/bd in       вставить камни из сумок в свободные гнёзда
/bd swap     вынуть, затем вставить
/bd toggle   включить или выключить аддон
/bd status   показать текущее состояние
```

`/blackdiamonds` — полный псевдоним `/bd`.

## Установка

Скопировать папку `BlackDiamonds` в `Interface\AddOns\`. Внешних зависимостей нет.

## Совместимость

Interface 30300. Хук ставится на `EquipmentManager_EquipSet`, поэтому работает и с нативной кнопкой «Надеть», и с командой `/equipset`, независимо от того, загружен ли ElvUI.
